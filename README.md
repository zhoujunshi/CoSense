# cosense Folder Description

This folder contains the core Python scripts for vehicle simulation, data collection, and analysis under different scenarios based on the Carla 0.9.15 simulation platform. The following provides a brief description of each script.

---

## 1. Vehicle and Map Utilities

- **Spectator.py**  
  Connects to the Carla simulation environment, controls the spectator view, and prints the current spectator location and orientation. It is mainly used for debugging and scene observation.

- **Waypoint.py**  
  Retrieves all recommended vehicle spawn points in the map, prints the first 10 spawn points as candidate starting positions, and selects the start and end points. It is suitable for route planning and vehicle initialization.

- **map.py**  
  Connects to the Carla simulation environment, outputs map spawn point information and map boundaries, and filters spawn points located on roads. It is used for scenario planning and selecting data collection regions.

- **passtime.py**  
  Automatically controls a vehicle to drive from a start point to an end point. It supports route visualization, trajectory drawing, and automatic lane changing. It also includes automatic resource cleanup, making it suitable for path-following and simulation testing.

---

## 2. Data Collection and Analysis

- **sim.py / simcurve.py / simmmmm.py / sime.py / simp.py / sim_6.py / sim_our.py / sim_test1.py / simtest2.py / simnewtest1.py / simnewtest2.py / simnewtest3.py / simnewtest4.py / simnewtest5.py, etc.**  
  These are the main simulation scripts for different scenarios, including illegal roadside parking, traffic condition simulation, and congestion analysis. They support sensing vehicles, background vehicles, automatic data collection, traffic light control, traffic flow statistics, congestion detection, and automatic saving of images and metadata.

  By adjusting the parameters in these scripts, the following functions can be implemented:

  - Generating illegally parked vehicles
  - Deploying sensing vehicles and collecting camera data
  - Simulating dense and congested traffic with background vehicles
  - Recording camera videos and vehicle states
  - Collecting traffic flow and congestion statistics
  - Simulating different weather conditions, image resolutions, and traffic light settings
  - Automatically cleaning up resources and supporting asynchronous/synchronous simulation modes

- **analyze_photos.py**  
  Batch-processes the images and metadata collected by vehicles, calculates the visible area of each vehicle at different locations, assigns scores, and outputs the ranking results. It is suitable for perception capability evaluation and environmental occlusion analysis.

- **duqu.py**  
  Loads `.npy` data files generated by vehicle depth cameras using NumPy and prints the data. It is mainly used for debugging and sensing data analysis.

---

## 3. Recommended Directory Structure

- `output/camera_images/`: stores images and metadata collected by vehicles.
- `output/analysis_results/`: stores image analysis results, such as rankings and scores.
- `output/parking_coordinates.txt`: stores parking coordinate information generated by some scripts.
- Other scripts, such as `sim_our.py`, may also export CSV files containing angular velocity, traffic flow, and other statistics.

---

## 4. Dependencies

- Python 3
- [Carla simulation platform](https://carla.org/)
- NumPy
- OpenCV (`cv2`)
- Other commonly used Python standard libraries

Some scripts may depend on different Carla versions. It is recommended to select the appropriate Carla version according to the script comments and the official Carla documentation.

---

## 5. Usage

1. Start the Carla simulation server. It is recommended to use a compatible map, such as `Town04` or `Town10HD`.
2. Run the required script according to the target task, for example:
   - Main simulation and data collection loop: `sim.py`, `simcurve.py`, `simnewtest1.py`, etc.
   - Route analysis and trajectory tracking: `passtime.py`
   - Spectator-view debugging: `Spectator.py`
   - Visible-area analysis: `analyze_photos.py`
3. Modify the script parameters according to the specific scenario, such as the number of vehicles, start and end positions, image resolution, and simulation duration.
4. It is recommended to debug the scripts step by step and ensure that all resources are properly cleaned up after each simulation.
5. The generated images, videos, and data files can be used for subsequent analysis and experimental results in research papers.
